## Story and outcome

As the owner, I want the orchestrator process to boot, create its database, and reject anonymous callers before any findings exist.

## Files in scope

- `src/vme_orchestrator/app.py`
- `src/vme_orchestrator/db.py`
- `src/vme_orchestrator/models.py`
- `src/vme_orchestrator/auth.py`
- `tests/orchestrator/test_auth.py`

## Do not touch

- Intake, router, notifier, digest, feedback forwarding (later stories)
- Runner code, except that this service checks `VME_RUNNER_TOKEN`

## Acceptance criteria

- AC1: `vme-orchestrator` serves FastAPI on port 8088. `GET /healthz` returns `{"status": "ok"}` with no auth and no data.
- AC2: SQLModel creates the section 6.6 tables on startup: `agents`, `findings`, `feedback`, `decisions`, `deliveries`, plus `schema_version`. `create_all` is enough. No Alembic in this story.
- AC3: Dependencies `require_runner`, `require_admin`, `require_feedback_or_admin` compare tokens in constant time. Wrong or missing token returns 401 with an empty body. Add a temporary authed route per dependency in tests, or attach the dependencies to placeholder routes that return 204. Remove nothing that later stories need; placeholder routes must be obviously named (`/v1/_auth_check/...`) and not part of the public contract, or test the dependencies by calling them with a mock request.
- AC4: Startup fails if any of `VME_RUNNER_TOKEN`, `VME_ADMIN_TOKEN`, or `VME_FEEDBACK_TOKEN` is missing or shorter than 32 characters.
- D17: `require_runner` checks `VME_RUNNER_TOKEN` only. There is no second orchestrator token.

## Build steps

1. Tables match section 6.6 columns, including finding status values `new`, `pushed`, `held`, `queued_digest`, `digested`, `dropped`, `expired`.
2. `findings.dedup_key` is indexed with `agent_id` and `created_at` for the 7-day lookup in VME-202. Uniqueness is not a SQL constraint, because duplicates are stored as `dropped`.
3. Bind `0.0.0.0:8088` inside the container. Host binding to the Tailscale IP is Compose (VME-401).
4. Tokens in tests are 32+ fake characters, not real secrets.

## Tests and done when

Auth matrix: each dependency accepts its token and rejects the others and a missing header. Startup test: short token aborts. `/healthz` is open. pytest, ruff, mypy green.

## Challenges and decision

`create_all` does not alter existing tables. Acceptable while the database is new. A later column change needs a written migration, not another silent `create_all`. Say that in `db.py`’s docstring.

Constant-time compare must not early-return on length in a way that skips the hash compare. Compare hashes of equal length.

The feedback token will eventually sit on the phone (VME-203). This story only checks length and role separation so a feedback token cannot call admin routes.
