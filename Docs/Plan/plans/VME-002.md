## Story and outcome

As the owner, I want the laptop to behave like a server so that it runs 24/7 safely with the lid closed.

## Files in scope

- `scripts/bootstrap_server.sh` (append idempotent lid and sleep functions)
- `docs/SERVER.md` (temperatures, battery inspection, power-limit result)

## Do not touch

- NVIDIA driver install (VME-003), Docker (VME-004), application code

## Acceptance criteria

- AC1: With the lid closed, the server still answers SSH after 10 minutes.
- AC2: Idle does not suspend or hibernate. `systemctl status sleep.target suspend.target hibernate.target hybrid-sleep.target` shows them masked.
- AC3: Battery health is written in `docs/SERVER.md`. A swollen battery is removed before the machine stays on 24/7. This is a physical check, not a script.

## Build steps

1. `/etc/systemd/logind.conf`: `HandleLidSwitch=ignore`, `HandleLidSwitchExternalPower=ignore`, `HandleLidSwitchDocked=ignore`. Then `sudo systemctl restart systemd-logind`.
2. `sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target`.
3. `sudo apt install -y lm-sensors && sudo sensors-detect --auto`. Record idle temperatures in `docs/SERVER.md`. Record load temperatures after the VME-003 GPU check or a short stress run.
4. Physical: clean fans and vents, use a cooling pad, inspect the battery for swelling. Write the result. Do not script this.
5. After VME-003, try `sudo nvidia-smi -pl 60`. If the driver says power limit is not supported, record that and stop. Do not retry with other watt values. Cooling and the Ollama limits in VME-401 are the fallback.
6. Add steps 1–2 to `bootstrap_server.sh` so a second run is a no-op.

## Tests and done when

A 24-hour lid-closed soak shows no sleep in the journal and the CPU stays under 90 °C. Record the journal command and the temperature readings in `docs/SERVER.md`. AC1 can be checked in 10 minutes. The soak is the story’s real done-when. Do not block later coding stories on the full 24 hours; do block “leave it unattended” on the soak.

## Challenges and decision

`systemd-logind` restart drops graphical sessions. An SSH session should survive. Masking sleep is host-wide and also stops intentional suspend. That is what this machine is for.

The 24-hour soak and the 10-minute lid check are different. Passing AC1 does not prove AC2 overnight. Journal snippets belong in `docs/SERVER.md`.

Decision: run the power-limit command only after VME-003, and treat “not supported” as success.
