## Story and outcome

As the owner, I want the Deal Scout plugin to match the agent contract so the runner can load it before any feed code exists.

## Files in scope

- `agents/deals_slickdeals/manifest.yaml` (section 6.5 of the master plan)
- `agents/deals_slickdeals/agent.py`
- `agents/deals_slickdeals/models.py`
- `agents/deals_slickdeals/config.example.yaml` (Appendix B, example interests only)
- `config/agents/deals_slickdeals.example.yaml` (same example)
- `agents/deals_slickdeals/tests/test_config.py`

## Do not touch

- Fetcher, parser, scoring
- Real server config under `/srv/vme`

## Acceptance criteria

- AC1: `manifest.yaml` matches section 6.5: id `deals_slickdeals`, tier `private`, domains `slickdeals.net`, `allow_cloud: false`, finding types `deal_match`, `watch_hit`, `price_drop`, `feed_health`, feedback actions `like`, `dislike`, `mute_store`, `mute_watch_item`.
- AC2: `DealsConfig` matches Appendix B. Validations: `poll_interval_minutes ≥ 10`; every feed URL is `https` and host `slickdeals.net` or a subdomain; interest and watch item ids are unique snake_case; each `max_price > 0`.
- AC3: `Agent.run()` returns `RunResult(findings_emitted=0, items_seen=0)`. A registry test loads the folder and calls `run()` with fakes.
- AC4: Both example YAML files validate against `DealsConfig`.

## Build steps

1. `scoring`, `semantic`, and `judge` blocks exist on the model with the Appendix B defaults so later stories do not reshape the file.
2. `judge.enabled` and `semantic.enabled` default true in the example, but `run()` ignores them until VME-306 and VME-307. Rules-only must still be representable by setting both false (D21).
3. Example interests stay the generic samples from Appendix B. Do not replace them with a real personal profile.

## Tests and done when

Config accept/reject cases and one registry load. pytest, ruff, mypy green.

## Challenges and decision

Manifest `interval_minutes: 20` and config `poll_interval_minutes: 20` can drift. The scheduler reads the manifest (VME-110). The config value is the agent’s own polite-poll floor. Document in `models.py` that the manifest interval must be ≥ the config floor. A test can assert the example files agree.

`allow_remote_search` exists on watch items and defaults false. This story only validates the boolean. No search URL is built.
