## Story and outcome

As the platform, I want one policy-enforcing AI gateway so personal data cannot reach a cloud model and model output is always schema-checked.

## Files in scope

- `src/vme_core/llm.py`
- `src/vme_core/errors.py` (`LLMPolicyError`, `LLMOutputError`, `LLMBudgetExceeded`, `LLMUnavailable`)
- `tests/core/test_llm.py`

## Do not touch

- Deal Scout prompts (VME-307)
- The runner’s per-run `budget_reset()` call site (VME-110). Expose the method here.

## Acceptance criteria

- AC1: `complete_json(system, user, schema: type[T], *, temperature=0.0, max_tokens=400) -> T` calls Ollama `POST /api/chat` with `format` set to `schema.model_json_schema()`, `stream=false`, and validates with pydantic.
- AC2: Invalid JSON or a schema mismatch retries once with the hint “Return ONLY valid JSON matching the schema”, then raises `LLMOutputError`.
- AC3: `embed(texts: list[str]) -> list[list[float]]` calls `POST /api/embed` in batches of 32.
- AC4: If the bound tier is not `public`, or `manifest.llm.allow_cloud` is false, or `VME_ALLOW_CLOUD_LLM` is false, any cloud provider raises `LLMPolicyError`. Phase 1 ships only `OllamaProvider`. The protocol exists so a cloud provider cannot be added by accident inside an agent.
- AC5: More than `max_calls_per_run` chat calls, or more than `max_embed_texts_per_run` texts, raises `LLMBudgetExceeded`. `budget_reset()` clears both counters.
- AC6: Every call is audited via VME-104. Private and sensitive tiers store a prompt hash and lengths, not the prompt.
- AC7: Chat timeout is 30 seconds. Embed timeout is 60 seconds. Connection failure raises `LLMUnavailable`.

## Build steps

1. `LLMProvider` protocol and `OllamaProvider` using `httpx` inside `llm.py` only. Base URL from `OLLAMA_URL`. Model names from `VME_LLM_MODEL` and `VME_EMBED_MODEL`.
2. `LLMGateway(provider, tier, spec, audit, agent_id)`.
3. Default models elsewhere are `qwen2.5:7b-instruct` and `nomic-embed-text`. The gateway does not pull models. It only calls a running Ollama.
4. There is no cloud class in the tree. AC4 is tested by a fake provider flagged `cloud=True` that the gateway refuses before the call.

## Tests and done when

Fake provider for policy and budget. respx for the Ollama JSON shape. One test for invalid-then-valid retry. One test that a private-tier audit row has no prompt text. No real Ollama. pytest, ruff, mypy green.

## Challenges and decision

Ollama’s structured-output `format` field has changed across versions. Lock the request body in a test: `format` is the JSON schema object, `stream` is false. If VME-401’s pinned Ollama rejects that shape, update this test and the ADR together. Do not guess a second shape now.

Callers must degrade when `LLMUnavailable` is raised (D21). The gateway does not catch that and return an empty embedding. Returning zeros would look like a real vector. Raise, and let VME-306 map that to `semantic_score=0`.

Budget counts texts, not embed HTTP calls. Three batches of 32 still count as 96 texts.

A 7B model on a 6 GB GPU can exceed 30 seconds on a cold load. `OLLAMA_KEEP_ALIVE` is VME-401. If the timeout proves too low on the hardware, change it in this module with a test and a note in the ADR, not with a silent retry loop.
