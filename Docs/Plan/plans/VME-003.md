## Story and outcome

As the owner, I want a stable GPU driver that still supports the Pascal GTX 1060 so Ollama can use it.

## Files in scope

- `scripts/bootstrap_server.sh` (append driver and toolkit functions)
- `docs/ADR/ADR-010-ollama-pin.md` (create; driver and CUDA only)
- `docs/SERVER.md` (record `nvidia-smi` summary)

## Do not touch

- Ollama image tag and digest (VME-401 fills those into the same ADR)
- Docker daemon log rotation (VME-004), except that this story may restart Docker after `nvidia-ctk`
- Application code

## Acceptance criteria

- AC1: `nvidia-smi` shows the GTX 1060 and a 580.x driver.
- AC2: The package pin prevents 590 and later from installing, and `apt-cache policy` (or the pin file) is copied into `docs/SERVER.md`. A hard hold that also freezes 580.x security updates does not satisfy AC2.
- AC3: `docker run --rm --gpus all nvidia/cuda:12.4.1-base-ubuntu22.04 nvidia-smi` succeeds and shows the same GPU.

## Build steps

1. On the MSI, confirm which Ubuntu release is installed and whether `nvidia-driver-580` (or `nvidia-driver-580-server`) exists in the configured repos. If the name differs, use the package that is actually the 580 branch and record the name. Do not install a 590+ driver.
2. Install that driver. Reboot. Confirm AC1.
3. Add an apt pin (or equivalent) so newer major branches cannot replace it, while 580.x updates still can. Record the pin file path.
4. Install the NVIDIA Container Toolkit from NVIDIA’s official repo. `sudo nvidia-ctk runtime configure --runtime=docker && sudo systemctl restart docker`.
5. Run the CUDA 12.4.1 container in AC3. If a newer CUDA 12.x tag is what the toolkit documents for this driver, record the tag that worked instead of forcing 12.4.1, and say why.
6. Write `docs/ADR/ADR-010-ollama-pin.md` with: GPU, driver version, the CUDA 12 constraint, the pin method, and an explicit “Ollama image tag: filled in by VME-401” line. Do not invent an Ollama tag.
7. Mirror the successful commands as idempotent functions in `bootstrap_server.sh`. A second run must not reinstall blindly if `nvidia-smi` already reports 580.x.

## Tests and done when

AC1–AC3 captured in `docs/SERVER.md`, and the ADR exists with the Ollama line left for VME-401. Jellyfin, if already installed, still starts after the Docker restart. Note that in `docs/SERVER.md`.

## Challenges and decision

Pascal support stays on the 580 branch, including Linux updates such as 580.173.02, with security support discussed through October 2028. Holding the metapackage blocks those updates. The master plan’s `apt-mark hold` step is replaced by D2.

`nvidia-ctk` rewrites `/etc/docker/daemon.json`. VME-004 must merge log rotation into that file, not replace it. This story should leave the file in place.

The CUDA base image is large. Pull it once, on a network that is allowed to reach Docker Hub, and do not leave a long-running CUDA container behind.
