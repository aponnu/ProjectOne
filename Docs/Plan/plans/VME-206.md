## Story and outcome

As the owner, I want a 👍 or 👎 on the phone to be stored and forwarded to the agent that produced the finding.

## Files in scope

- `src/vme_orchestrator/feedback.py`
- Route `POST /v1/feedback/{finding_id}`
- `tests/orchestrator/test_feedback.py`

## Do not touch

- Deal Scout learning math (VME-309). This story delivers `Feedback` and stops.
- Decision answers (VME-207)

## Acceptance criteria

- AC1: The route accepts the feedback token or the admin token. `action` must be in that agent’s `feedback_actions` (from the `agents` row or a cached manifest). It stores `feedback` with `source=ntfy` when the feedback token was used and `source=cli` when the admin token was used. Success is 204.
- AC2: The orchestrator POSTs `Feedback`, including `finding_snapshot`, to the runner `POST /v1/agents/{agent_id}/feedback` with `VME_RUNNER_TOKEN` (D17). On failure, `forwarded_ok=false`. A job every 10 minutes retries those rows.
- AC3: Unknown action is 422. Unknown finding is 404.
- AC4: The same action on the same finding within 1 hour is stored once and returns 204.

## Build steps

1. Build `finding_snapshot` from the stored finding so the agent does not need the orchestrator database.
2. Retry job uses the orchestrator scheduler. Cap attempts only by leaving `forwarded_ok=false` until success. Do not drop feedback.
3. Tests mock the runner with respx. No real runner process required.

## Tests and done when

Forward success, forward failure then retry, idempotency inside and outside the hour, 404 and 422. pytest, ruff, mypy green.

## Challenges and decision

The phone only has the feedback token (D19). This route must not accept that token for admin paths. Reuse `require_feedback_or_admin`.

Idempotency is per action. A like and a later dislike within the hour are both stored. That matches “same action”.

The runner returns 500 when `on_feedback` raises (VME-110). Those stay `forwarded_ok=false` and retry. If the agent always raises, the log will be noisy. Log at warning once per finding id per hour.
