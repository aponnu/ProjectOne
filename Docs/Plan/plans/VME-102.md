## Story and outcome

As the platform, I want strict shared models so that agents and the orchestrator agree on findings, manifests, and feedback.

## Files in scope

- `src/vme_core/contracts.py`
- `src/vme_core/timeutil.py` (`utcnow()` returning timezone-aware UTC)
- `tests/core/test_contracts.py`

## Do not touch

- Config loading (VME-103), HTTP, LLM, runner, orchestrator routes

## Acceptance criteria

- AC1: Models from master plan section 6.5 exist with the stated limits: `DataTier`, `Urgency`, `ActionSpec` (label max 24), `Finding` (title 120, summary 500, score 0–1, dedup key 128, at most 3 actions, payload documented as ≤ 8 KB at emit time), `Feedback`, `RunResult`, `HealthStatus`. Also `ScheduleSpec`, `NetworkSpec`, `LLMSpec`, `AgentManifest`, `Decision`, `FindingDraft`.
- AC2: `AgentManifest` loads the Deal Scout manifest YAML from section 6.5. It rejects an id that is not snake_case, a missing tier, and a schedule that sets both `interval_minutes` and `cron`.
- AC3: `Finding` rejects a score outside 0–1, more than 3 actions, and a title over 120 characters.
- AC4: `FindingDraft` is `Finding` without `agent_id` and `tier`.

## Build steps

1. Pydantic v2. `ScheduleSpec`: exactly one of `interval_minutes` (≥ 5) or `cron`; `jitter_seconds`; `timeout_seconds` default 300.
2. `AgentManifest.load(path: Path)` uses `yaml.safe_load` then model validation. Add PyYAML in this story if VME-101 did not already lock it.
3. `Decision` fields must be enough for VME-207 later: question, options, status, answer, expiry. Do not implement the decision API here.
4. `utcnow()` in `timeutil.py`. Finding timestamps use it. Store timezone-aware UTC, never naive datetimes.
5. `extra="forbid"` on public models so typos fail fast.

## Tests and done when

`tests/core/test_contracts.py` covers valid and invalid cases for every AC. 100% line coverage of `contracts.py`. `uv run pytest`, ruff, and mypy stay green.

## Challenges and decision

Section 6.5 shows `Finding` and `AgentContext` together. This story is models only. `AgentContext` is VME-108.

`HttpUrl` rejects some feed links with odd characters. Test with a normal `https://slickdeals.net/f/123` link. If pydantic’s URL type rejects a fixture later, VME-303 records the exception. Do not loosen the type in this story without a failing real URL.

Payload size is enforced at `ctx.emit` (VME-108), not only by the model, because a dict has no inherent byte size. The model docstring should say that.

`interval_minutes ≥ 5` in the contract and Deal Scout’s own minimum of 10 are different layers. The contract stays at 5. The agent config stays at 10.
