## Story and outcome

As the owner, I want one validated place for environment settings and my notification profile so that typos fail fast.

## Files in scope

- `src/vme_core/config.py`
- `config/profile.example.yaml` (Appendix A of the master plan, placeholder owner name “Me”)
- `.env.example` (fill names if VME-101 left it thin)
- `tests/core/test_config.py`

## Do not touch

- `src/vme_orchestrator/cli.py` beyond what VME-101 stubbed. The CLI command is VME-209 (D7).
- Real `config/**/*.yaml` (gitignored)

## Acceptance criteria

- AC1: `Settings` (pydantic-settings) reads: `VME_DATA_DIR`, `VME_CONFIG_DIR`, `VME_AGENTS_DIR`, `VME_ORCHESTRATOR_URL`, `VME_RUNNER_URL`, `VME_RUNNER_TOKEN`, `VME_ADMIN_TOKEN`, `VME_FEEDBACK_TOKEN`, `VME_PUBLIC_BASE_URL`, `OLLAMA_URL`, `VME_LLM_MODEL`, `VME_EMBED_MODEL`, `VME_ALLOW_CLOUD_LLM` (default false), `NTFY_URL`, `NTFY_TOPIC`, `NTFY_TOKEN`, `HTTP_USER_AGENT`, and `VME_AUDIT_STORE_PUBLIC_PROMPTS` (default false, used by VME-104).
- AC2: `UserProfile` loads Appendix A and validates the time zone (`zoneinfo`), `HH:MM` quiet hours and digest times, and numeric thresholds in range.
- AC3: `load_agent_config(agent_id, model)` reads `<config_dir>/agents/<id>.yaml`. A missing file returns a typed “skipped” result and logs once. It does not raise.
- AC4: `validate_profile(path) -> None` raises a pydantic `ValidationError` (or a thin wrapper) with field locations. The CLI printing of that function is VME-209, not this story (D7).

## Build steps

1. Implement loaders in `config.py`. Profile model fields match Appendix A, including `narrative_brief: bool = false`.
2. Commit `config/profile.example.yaml` with the sample values from Appendix A. No real interests (those live in the agent config, VME-301).
3. Default `HTTP_USER_AGENT` to `VirtualMe/0.1 (personal RSS reader)` so VME-105 can rely on it.
4. Token fields are optional at load time in unit tests. VME-201 is what refuses tokens shorter than 32 characters at process start. Document that split in the module docstring so this story does not grow an orchestrator lifespan.

## Tests and done when

Tests: valid profile, bad time zone, bad `HH:MM`, threshold out of range, missing agent config does not raise. `uv run pytest`, ruff, and mypy green.

## Challenges and decision

Quiet hours that cross midnight (22:00–07:00) are valid input. This story only checks the clock format. The wrap-around comparison is VME-204.

`America/Chicago` must be a real `zoneinfo` key. Do not accept a bare offset.

Agent configs and the profile are different files. Do not put watchlist items on `UserProfile`.
