## Story and outcome

As the owner, I want deals that match the meaning of an interest, not only its keywords.

## Files in scope

- `agents/deals_slickdeals/matcher.py` or a new `semantic.py` if `matcher.py` is already near 300 lines
- `agents/deals_slickdeals/tests/test_semantic.py`

## Do not touch

- The pure rule function’s existing tests, except to add a call-through that leaves `semantic_score` at 0 when disabled

## Acceptance criteria

- AC1: Interest embeddings (`description` plus keywords) are cached in `_kv` under `interest_emb:<id>:<sha256 of text>`. A text change misses the cache.
- AC2: For each non-blocked new deal, embed `title + " — " + description_text[:300]`, newest first, at most `semantic.max_deals_per_run` (default 150).
- AC3: `semantic_score = clamp((max_cosine − sim_floor) / (sim_ceiling − sim_floor), 0, 1)` with defaults floor 0.35 and ceiling 0.75.
- AC4: On `LLMUnavailable` or any embed error, `semantic_score` is 0 for the rest of the run, one warning is logged, and rule scores still flow (D21).

## Build steps

1. If `semantic.enabled` is false, do not call `embed`.
2. Cosine is computed locally against cached interest vectors. The gateway is only used to embed.
3. Use the gateway budget. Do not catch `LLMBudgetExceeded` and keep going as if vectors existed; treat it like unavailability for the rest of the run (score 0).

## Tests and done when

Fake embedder with fixed vectors: above ceiling, below floor, mid. Cache hit does not embed again. Degraded path. pytest, ruff, mypy green.

## Challenges and decision

150 embeddings plus interest vectors on CPU/GPU can stall a 20-minute poll on a 1060 if the model was unloaded. The cap stays. Do not raise it in this story.

`nomic-embed-text` dimensions must be whatever the model returns. Do not hardcode 768 in a check that fails the run. A dimension mismatch between cache and a new model invalidates the cache key because the text hash will not change. Include the model name in the cache key (`interest_emb:<model>:<id>:<sha>`). That is a small extension of AC1 and avoids mixed vectors.

Semantic score is optional input to VME-308. When this story has not run, score is 0.
