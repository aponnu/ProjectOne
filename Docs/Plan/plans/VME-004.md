## Story and outcome

As the owner, I want Docker Engine and the Compose plugin installed, with rotated container logs, without breaking the NVIDIA runtime or Jellyfin.

## Files in scope

- `scripts/bootstrap_server.sh` (append Docker install and daemon.json merge)
- `docs/SERVER.md` (docker version, daemon.json after merge, Jellyfin still up)

## Do not touch

- `docker/compose.yml` (VME-401)
- The NVIDIA driver pin (VME-003)
- Application code

## Acceptance criteria

- `docker compose version` works (Compose v2 plugin, not the legacy `docker-compose` binary).
- `/etc/docker/daemon.json` sets `log-driver` to `json-file` with `max-size` `10m` and `max-file` `5`.
- The `nvidia` runtime entry written by `nvidia-ctk` is still present after the merge.
- Jellyfin, if it is already on this host, still runs after the Docker restart.

## Build steps

1. Install Docker Engine and the `docker-compose-plugin` from Docker’s official apt repo for this Ubuntu release. Do not use the distro `docker.io` package if it lags the Compose plugin.
2. Add the operator user to the `docker` group. Note that the group applies on the next login.
3. Read the existing `/etc/docker/daemon.json`. Merge log rotation into it. Do not drop `runtimes.nvidia` or `default-runtime` if `nvidia-ctk` set them.
4. Restart Docker. Confirm `docker info` shows the nvidia runtime and the log driver.
5. Confirm Jellyfin’s container or service is healthy if it was healthy before.
6. Put the install and the merge in `bootstrap_server.sh`. The merge must be idempotent: a second run does not duplicate keys.

## Tests and done when

Record `docker compose version`, `docker info` lines for runtime and logging, and the Jellyfin check in `docs/SERVER.md`.

## Challenges and decision

Replacing `daemon.json` wholesale deletes the GPU runtime and makes VME-003 AC3 fail on the next boot. This story is a merge.

Docker’s iptables rules bypass UFW. That is expected. This story does not publish Virtual Me ports. When VME-401 does, it binds them to the Tailscale IP (D6).
